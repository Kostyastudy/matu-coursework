# 码图课程作业

在 VS Code 中查看电子科技大学码图课程作业，编辑 `.c` / `.cpp` 文件，提交并查看网站评测。

## 使用

1. 打开 VS Code，点击左侧活动栏中的“码图”图标。
2. 点击“登录”，在 VS Code 内输入账号和密码。
3. 展开课程、作业，点击题目。源码在左侧打开，题面在右侧打开。
4. 写完后选中源码编辑器，按 `Ctrl+Alt+Enter`；也可以点击编辑器顶部的上传图标。
5. 在题面中的“评测与记录”查看分数、网站错误信息和历史记录。评测尚未结束时点击刷新图标。

安装后如果暂时看不到“码图”，在命令面板执行“开发人员: 重新加载窗口”。扩展需要在受信任的本地工作区中启用。

快捷键仅在与码图题目关联的源文件中生效。点击题面中的上传图标时，当前编辑的源码必须属于同一道题。

首次打开题目只创建空文件，不生成答案。网站要求 C 时使用 `.c`，要求 C++ 时使用 `.cpp`，题面明确指定文件名时优先使用该文件名。已有源码不会被覆盖。

默认作业目录为 `C:\Study\matu-homework`，可在设置中搜索 `matu.homeworkDirectory` 更改。更改目录不会移动已有作业；切回原目录可继续使用原来的关联。目录按账号、课程、作业和题目编号分开，账号目录使用不可直接辨识的标识。

## 登录与网络

密码只由 VS Code 安全存储保存在本机，不写入项目、配置、提交记录或日志。使用命令“码图: 退出并清除登录信息”可清除登录凭据，保留本地源码。

**当前网站使用 HTTP，账号密码和源码在网站传输中不加密。本机安全存储不能改变网站传输方式。**

登录过期时尝试重新登录。密码发生变化后，退出并重新登录。断网时已有源码与缓存题面仍保留；尚未读取过的题目需要联网。

## 提交与评测

- 先保存当前源文件，再读取网站的实际上传表单，通过单文件接口上传。
- 代码填空题显示网站提供的程序框架：只有一处填空时可在空文件中写填空代码，也可提交仅补全空位的完整程序；多处填空时提交完整程序。扩展按网站的填空入口提交，不生成答案。
- 保留课程作业关联，避免同题在不同作业下被交错。
- 同一题上传与评测查询期间阻止重复提交。
- 网站返回的 `100` 分且已完成评测显示“已通过”；其他情况显示网站原有状态和分数。
- 自动查询最多两分钟，之后可手动刷新。网站错误详情保持原文，不由扩展自行判题。
- 上传超时后先查询提交记录，不自动重复上传。若仍无法确认，保留待确认状态并阻止再次上传；核对记录后可点击“结束跟踪”。此操作不会撤销网站已有提交。
- 多条新记录导致无法确定本次编号时显示待核对状态，不将某条历史成绩当作本次结果。

第一版支持课程作业的单个源文件和代码填空提交，不包含本地编译运行、公共题库、历史源码恢复或 AI 判题。

## 安装与开发

安装交付的 `matu-coursework-0.1.0.vsix`，或使用：

```powershell
code --install-extension C:\Study\matu-coursework-0.1.0.vsix
```

源码位于 `C:\Study\matu-vscode`。开发命令：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run test:vscode
npm.cmd run package
```

`test:vscode` 默认下载独立的 VS Code 1.141.0 便携副本，使用隔离配置进行扩展宿主测试，不接触真实账号或上传真实作业。也可用临时环境变量 `MATU_VSCODE_EXE` 指定本机可用的 VS Code 程序。

`smoke:live` 是只读网站验证，仅从临时环境变量 `MATU_READ_ACCOUNT` 和 `MATU_READ_PASSWORD` 读取凭据；只登录、读取课程与题目、检查上传表单和读取历史评测，不上传源码。
